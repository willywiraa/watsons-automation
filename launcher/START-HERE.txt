WatsonsTester: Watsons STAGING automation launcher
==================================================

A window with two pages:
- Automation: place a test order on the Watsons STAGING website (never the real shop) and
  approve it in the staging backoffice (with a backoffice account), or approve an order that
  already exists.
- Logs / History: every run, with its result, error and screenshots.


BEFORE THE FIRST RUN (once per PC)
----------------------------------
1. You need Windows 10 or 11 with Microsoft Edge (already part of Windows).

2. Install Node.js, the "LTS" version (20 or newer), from https://nodejs.org
   The default options are fine.

3. Unzip WatsonsTester.zip into a folder of your own, e.g. Documents\WatsonsTester.
   If you received the zip by email, Teams or a download: first right-click the zip,
   choose Properties, tick "Unblock", click OK, and only then unzip it.

4. Open the file ".env" in that folder with Notepad and fill in the staging test account and,
   if you have one, the staging backoffice account (ask the person who sent you this tool):

       WATSONS_USERNAME=the account's email
       WATSONS_PASSWORD=the account's password
       WATSONS_BACKOFFICE_USERNAME=the backoffice user name
       WATSONS_BACKOFFICE_PASSWORD=the backoffice password

   Without the two backoffice lines you can still place orders: they stop at "Thank you for
   your order" and wait for someone with a backoffice account to approve them.

   Optional: WATSONS_OPERATOR=your name (shown in Logs / History; else your Windows user name).
   Save and close. Keep .env private, and leave it out if you ever pass the folder on.

5. Your PC must be able to open the staging website (its address is in .env). Open it in
   Edge once to check.


RUNNING A TEST
--------------
1. Double-click WatsonsTester.exe. A black window and the launcher window open: keep both
   open. If Windows says "Windows protected your PC", click "More info", then "Run anyway".
   If Windows says it "cannot access the specified device, path, or file" (company PCs can
   block new programs), double-click "Start without exe.cmd" instead: same launcher.
2. On the left, choose what to run:
   - Place new order: paste the PLUs, one per line ("10321 2" means two of PLU 10321),
     choose the delivery method and the mode (Express or Standard). Click Place test order
     and confirm.
   - Approve existing order: type the order number (07091012 or WTCSG07091012), click
     Approve order and confirm. No new order is created.
3. The bar at the top must say Ready. If it says Not ready, it names what to fix ("Show
   checks" lists every check).
4. The test runs in "Live browser" in the launcher window (no separate Edge window opens); you
   can watch it and use it there. A new order is placed and approved in the staging backoffice;
   the run ends once the order is ORDER_EXTRACTED. If it is still at "Order Split" a minute after
   that, the run ends anyway and says extraction is still pending: wait a few minutes, then check
   it in the backoffice. Without a backoffice account, the run ends on the "Thank you for your
   order" page: Completed, with a note that the order awaits approval. The launcher shows
   Completed with the order number, No change, or Failed. You can start the next run straight
   away.
5. If something needs your decision before Checkout (a product out of stock, not found or not
   addable, a product the delivery can't take, an error), the run pauses and asks you in a card
   above Live browser. Click one of its buttons (for example Skip product and continue, Replace
   with another PLU, Use Standard instead, Try Home Delivery, Retry or Stop automation): the run
   goes on from there. It waits for you up to 30 minutes. Your choice is kept in the run's log
   and in Logs / History.
6. When a run fails, the launcher shows the step it failed at, with the message, the time, the
   page and a screenshot. "Copy error report" puts it on the clipboard for Teams or email; it is
   also saved as error-report.txt.
7. Logs / History lists every run. The evidence of each run (screenshots, log, report)
   is in the "reports" folder. An order that is Awaiting approval has an "Approve" button, for
   whoever has a backoffice account (the Automation page lists these orders on the left too).


THE HOSTED VERSION (if your team runs WatsonsTester on the server)
----------------------------------------------------------------
Then you don't need this folder: open the address your admin gives you in Edge (on the Watsons
network or VPN), sign in, enter your own staging testing account (and backoffice account, if you
have one) under Accounts and run. You enter them once: the server remembers them for your next
sign-in, locked with your sign-in password (untick Remember if you'd rather not). They are used
only for your runs and never shown to anyone else. Without a backoffice account, your orders stop at
"Thank you for your order" and wait for someone to approve them. You watch and can use the run's
browser in "Live browser"; the run ends by itself when it is done.
Logs / History shows everyone's runs.


GOOD TO KNOW
------------
- Every "Place new order" run places a real order on STAGING (a test payment with OTP 1234)
  and, with a backoffice account, approves it in the staging backoffice. "Approve Order" is
  clicked at most once; if its result is unclear, the launcher says so and you check the order
  in the backoffice yourself.
- Each order run first empties the test account's bag. Two people using the same test account
  at the same time spoil each other's runs: take turns, or each use your own test account.
- If Windows refuses to start WatsonsTester.exe, double-click "Start without exe.cmd"
  instead: it opens the same launcher.
